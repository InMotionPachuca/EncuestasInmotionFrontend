Registro de Clientes y Facturación

Capture los datos comerciales del cliente y de la unidad para generar el expediente de facturación.

Datos Comerciales del Cliente

El nombre es requerido
El apellido es requerido
Ingrese un correo electrónico válido
El teléfono debe tener 10 dígitos numéricos
El asesor es requerido
Seleccione una sucursal

Datos de la Unidad y Facturación

El modelo es requerido
El número de factura es requerido
El número de serie es requerido
Ingrese un año válido (2015 - 2027)
Seleccione si el vehículo es Nuevo o Seminuevo
