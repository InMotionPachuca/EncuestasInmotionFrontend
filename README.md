📊 Sistema de Encuestas de Satisfacción a Clientes (CXI) - InMotion
Sistema web integral desarrollado para la gestión, emisión, personalización y análisis en tiempo real de encuestas de satisfacción de servicio y ventas para distintas sucursales automotrices.

🛠️ Tecnologías Utilizadas
Frontend: Angular, TypeScript, HTML5, CSS3, Chart.js, Bootstrap / FontAwesome.

Backend: Java, Spring Boot, Spring Data JPA.

Base de Datos: PostgreSQL / Oracle.

Herramientas adicionales: XLSX (procesamiento de datos masivos desde Excel), jsPDF (generación de reportes).

✨ Características Principales
📈 Dashboard Interactivo (CXI):

Control de métricas clave (Total de encuestas, Respondidas, Pendientes y Tasa de respuesta).

Cálculo de NPS Score: Calibrado para encuestas basadas en escala de 1 a 5 estrellas (Promotores, Pasivos y Detractores).

Visualización gráfica por marcas y evolución temporal.

👨‍💼 Módulo de Asesores de Servicio:

Métricas individuales de rendimiento y calificación de atención por asesor.

Vinculación automática entre encuestas respondidas y el asesor asignado.

📩 Gestión e Importación Masiva:

Importación desde archivos Excel para la creación automatizada de encuestas.

Generación dinámica de plantillas personalizadas y banners para envío directo por WhatsApp.

Modales unificados con vista previa de imagen y copiado directo de plantillas.

📋 Respuestas e Interfaces Congeladas:

Vista para el cliente final accesible mediante token seguro.

Datos informativos congelados (Nombre del Cliente, Email y Asesor) no modificables durante la respuesta.
